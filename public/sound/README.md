# 스크린 뷰 배경음악

`#/screen` (빔프로젝터) 화면의 배경음악. 효과음(카운트다운 틱, 시간 종료 "땡",
정답 차임)은 항상 `src/lib/sound.js` 합성이라 파일이 필요 없다. **배경음악은
파일이 있어야 나온다** — 없으면 조용히 지나간다.

## 현재 파일 — `bgm.mp3` · `game2.mp3`

둘 다 사용자가 준 플레이리스트 원본
(`[Playlist] 신나는 BGM 텐션UP 놀이음악 레크레이션 노래 체육시간음악
기분전환하고 싶을 때.mp3`, 64분 · 92.5MB · 192kbps)에서 잘라 만들었다.
원본을 그대로 웹에 올리면 스크린 노트북이 92.5MB 를 통째로 내려받아야 해서
로딩이 느리고 저장소도 무거워진다.

| 파일 | 원곡 구간 | 쓰는 곳 |
|---|---|---|
| `bgm.mp3`   | 0:05 ~ 4:05     | 로비 · 게임1 · 리더보드·시상 |
| `game2.mp3` | 33:25 ~ 37:25   | 게임 2 (33:25부터 다른 곡으로 바뀌는 지점이라 게임 2 전용으로 따로 잘랐다) |

둘 다 같은 방식으로 처리:
- 라우드니스 정규화(-16 LUFS) — 구간별 볼륨 배율(아래)이 예측 가능하게
- 시작 1초 페이드인 + 끝 3초 페이드아웃 — 루프 지점 클릭 노이즈 방지
- 112kbps 로 재인코딩 → 각 3.3MB (92.5MB → 3.3MB)

`src/lib/sound.js` 의 `BEDS` 에서 구간별 볼륨만 다르게 준다:
로비 0.3 · 게임1 0.1(대화 방해 안 되게 아주 작게) · 게임2 0.22 · 리더보드 0.38.

⚠ `bgm.mp3`(0:05~4:05)는 내(에이전트)가 듣고 고른 구간이 아니라 원본 맨 앞을
기계적으로 잘랐을 뿐이다. `game2.mp3`(33:25~37:25)는 사용자가 지정한 구간.
다른 데도 어색하게 끊기거나 분위기가 안 맞으면 "X분 X초부터 잘라줘"처럼
알려주면 다시 잘라줄 수 있다.

## 다른 파일로 바꾸는 법

이 폴더에 `bgm.mp3` 를 같은 이름으로 덮어쓰면 그대로 반영된다. 구간별로
다른 곡을 쓰고 싶으면 `lobby.mp3` · `game1.mp3` · `game2.mp3` ·
`leaderboard.mp3` 로 따로 넣고 `src/lib/sound.js` 의 `BEDS` 경로를 그만큼 바꿔달라고 하면 된다.

- 이음새 없이 반복되는(loop-friendly) 트랙이 좋다.
- 저작권: 상업적 사용 가능한 무료 음원만. (예: YouTube 오디오 보관함, Pixabay Music)
