# 스크린 뷰 배경음악 (선택)

`#/screen` (빔프로젝터) 화면의 배경음악. **없어도 동작한다** — 파일이 없으면
`src/lib/sound.js` 가 Web Audio 로 만든 잔잔한 합성 패드로 자동 대체한다.
효과음(카운트다운 틱, 시간 종료 "땡", 정답 차임)은 항상 합성이라 파일이 필요 없다.

## 넣는 법

이 폴더에 아래 이름으로 mp3 를 두면 자동으로 그 파일을 루프한다.

| 파일 | 구간 | 권장 |
|---|---|---|
| `lobby.mp3`       | 로비(입장 대기)        | 잔잔한 앰비언트 |
| `game1.mp3`       | 게임 1 (3T1F)         | 아주 작게, 대화 방해 안 되게 |
| `game2.mp3`       | 게임 2 (대기+문제풀이) | 살짝 긴장감 있는 베드 |
| `leaderboard.mp3` | 중간 리더보드·최종 시상 | 축하 분위기 |

- 이음새 없이 반복되는(loop-friendly) 트랙이 좋다. 1~3분이면 충분하다.
- 볼륨은 코드에서 구간별로 낮춰 재생하므로(로비 0.3 / 게임1 0.1 / 게임2 0.22 /
  리더보드 0.38) 파일 자체는 일반 레벨로 둬도 된다.
- 저작권: 상업적 사용 가능한 무료 음원만. (예: YouTube 오디오 보관함, Pixabay Music)
